# 这里的照片是示例

`albums/` 下的三个相册目前指向你自己电脑里的照片（软链接，不占额外空间）：

| 相册 | 指向 |
| --- | --- |
| `01-人像` | `~/Desktop/人像摄影作品/` |
| `02-美食` | `~/Desktop/jpg/` |
| `03-航拍` | `~/Desktop/jpg/` |

这样做的原因：演示一下"照片放在别处、网站只拿压缩副本"这个流程，和 NAS 挂载的用法是一样的。

## 换成你自己的内容

在管理台里删掉这三个相册，建新的就行。或者直接在 Finder 里操作：

1. 删掉 `albums/` 下不要的相册文件夹；
2. 新建文件夹当相册，名字前面加数字控制顺序（`01-人像`）；
3. 把照片拷进去；
4. 回管理台点「生成」。

## 注意

软链接指向的文件一旦移动或删除，这里就会失效（构建时会跳过并提示）。如果希望项目自带一份独立的副本，把照片复制进来、删掉软链接即可。

原图不会进 git 仓库（根目录 `.gitignore` 已经排除），只会留在本机或 NAS 上。
