# 上线部署手册

## 你会得到什么

- 一个纯静态摄影站，不依赖服务器，也不需要网站托管费用；
- 一个本机管理台，用来上传、排序、写文案、一键发布；
- 一个可以直接指向 NAS 的内容目录。

生成的网站只用到 HTML / CSS / JavaScript，没有框架、没有构建依赖。十年后拿出来还能跑。

## 准备

- macOS 自带的 `python3` 和 `sips`（已经够用，不用装任何东西）
- `git`
- 一个 GitHub 账号

检查一下：

```bash
python3 -V
git --version
```

## 第一步：确认本机能看到效果

进入项目目录，双击：

```
tools/摄影站管理台.command
```

第一次打开 macOS 可能会拦（"无法验证开发者"），右键点它 → 打开 → 再点"打开"，之后就不会再问了。

终端里出现 `管理台已启动：http://127.0.0.1:8765` 后，浏览器会自动或手动打开这个地址。左上角点「预览网站」就能看到成品。

想只看网站、不开管理台也可以：

```bash
cd web && python3 -m http.server 8000
```

然后访问 `http://127.0.0.1:8000`。

> 注意：直接双击 `web/index.html` 也能看，但浏览器的 `file://` 协议会限制一部分功能，用上面的方式更准确。

## 第二步：建 GitHub 仓库

打开 https://github.com/new ，仓库名建议：

```
dollar-nong-gallery
```

- 选 **Public**（Public 才能免费用 Pages；Private 也能用 Pages，但有条件限制）
- **不要**勾选 "Add a README file"，保持空仓库
- 建好后你会看到地址，长这样：`https://github.com/dollarnong-jpg/dollar-nong-gallery.git`

## 第三步：推上去

在项目目录里执行（把地址换成你自己的）：

```bash
cd "<项目目录>"
git init -b main
git add -A
git commit -m "初始化摄影站"
git remote add origin https://github.com/dollarnong-jpg/dollar-nong-gallery.git
git push -u origin main
```

`git push` 会要求登录。GitHub 现在不接受账号密码，需要 Personal Access Token：

1. 打开 https://github.com/settings/tokens?type=beta
2. Generate new token，Repository access 选 Only select repositories → 选 `dollar-nong-gallery`
3. Permissions → Repository permissions → **Contents: Read and write**，**Pages: Read and write**
4. 生成后复制那串 `github_pat_...`
5. `git push` 时用户名填 GitHub 用户名，密码粘贴这串 token

macOS 的钥匙串会记住它，之后不用再输。

## 第四步：打开 Pages

仓库页面 → **Settings** → 左侧 **Pages**。

有两种发布方式，选一种：

### 方式一：GitHub Actions（推荐，项目里已经配好了）

- Source 选 **GitHub Actions**
- 什么都不用改

项目里的 `.github/workflows/pages.yml` 会在每次推送到 `main` 且 `web/` 有变化时，自动把 `web/` 目录发布出去。

### 方式二：直接从分支发布（不想用 Actions 的话）

GitHub Pages 只能从**仓库根目录**或**根目录下的 `/docs`** 发布，而我们的网站在 `web/`。所以要么：

- 打开管理台 → 「内容目录设置」→ 把"网站输出目录"改成 `../docs`，再把 `web/` 里的东西挪到 `docs/`；或者
- 直接用方式一。

改完之后：Source 选 **Deploy from a branch** → Branch 选 `main`、目录选 `/docs` → Save。

### 发布地址

几分钟后，你的站点地址是：

```
https://dollarnong-jpg.github.io/dollar-nong-gallery/
```

## 第五步：日常更新作品

1. 双击 `tools/摄影站管理台.command`
2. 左侧选相册（或点「+ 新建」）
3. 把照片拖进上面的虚线框
4. 填相册名字、副标题、简介；点某张图上的 ★ 设为封面
5. 点右上角「生成」，等进度跑完
6. 点「发布到线上」，等提示成功
7. 一到两分钟后刷新线上站点

整个过程不需要碰命令行。

## 常见问题

**线上没有样式，只有一堆黑字**

资源路径问题。检查 `web/index.html` 里是不是写了以 `/` 开头的路径。本站全部用相对路径，如果你手工改过，改回相对路径。

**图片不显示，控制台报 404**

多半是发布了但没重新构建，`web/media/` 里没有对应文件。在管理台点一次「生成」，再发布。

**发布报错 "not a git repository"**

项目目录还没 `git init`，或者你把项目复制到了别的地方。回到第三步重做一遍。

**仓库太大 / 推送很慢**

原图不应该进仓库。检查根目录的 `.gitignore` 是否还在，特别是这几行：

```
content/albums/*/*
!content/albums/*/_album.json
```

如果之前误提交过原图，执行 `git rm -r --cached content/albums` 把它们从版本控制里移除（本地文件不会删）。

**想换站点名字**

管理台 →「站点信息与联系方式」→ 改英文站名和中文站名 → 生成 → 发布。

**想在手机上看效果**

管理台是绑定在 `127.0.0.1` 的，手机连不上。想用手机管理，见《03-NAS 挂载文件夹自动更新.md》里的方案 B。
